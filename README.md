# 每日启动打卡（本地网页）

## 使用方式

1. 直接双击打开 `index.html`（或拖进浏览器）。
2. 填写/勾选你的启动模板内容。
3. 点「开始」启动 25 分钟计时（会自动写入开始时间）。
4. 点「导出 Markdown」把本轮记录复制/下载，贴到你的笔记里即可。

## 数据存储

- 记录保存在浏览器本地 `localStorage`（不联网、不上传）。
- 你可以用「历史记录」下拉框加载/继续编辑以往记录。

## 记忆模式（跨设备）

- 页面内可启用「记忆模式（GitHub Gist）」实现跨设备同步。
- 操作流程：
  1. 填写带 `gist` 权限的 GitHub Token。
  2. 首次可点「创建云端仓库」自动生成 Gist（会得到 Gist ID）。
  3. 另一台设备填同一个 Token + Gist ID，点「从云端下载」即可恢复记录。
  4. 可勾选「自动同步（保存后自动上传）」。
- 提醒：Token 会保存在当前设备浏览器本地，请只在你自己的设备使用。
